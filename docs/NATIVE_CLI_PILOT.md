# Native CLI: локальный пилот

Состояние на 2026-09-06, Europe/Moscow. Это текущая реализация, не заявление
о готовности всех платформ.

| Действие | Реализованный flow |
| --- | --- |
| Команда CLI | Буквальный ввод в принадлежащий сессии терминал, без препроцессинга и inference-запроса. Навигационные команды Bria остаются у Bria. |
| Выбор модели | Настоящий экран CLI, универсальные стрелки, Enter, Esc, Tab и Space. Текущая модель читается из CLI и отображается в заголовке карточки. |
| Обычный запрос | Отправляется в тот же CLI; принятие, инструменты и финал сверяются с журналом точной provider-сессии. |
| Закрытие и перезапуск | Подтверждение закрытия, архивация непустой / удаление пустой сессии, возврат к предыдущей. Перезапуск завершает принадлежащие боту процессы и восстанавливает точную provider-сессию. |

Claude под root без уже существующего поддержанного CLI sandbox-окружения
использует разрешённый `--permission-mode auto` вместо запрещённого самим CLI
bypass. Bria не подменяет пользователя или sandbox-флаги. Ошибки старта
записываются с длительностью и безопасной классификацией, без исходного stderr.
Пустая сессия после неудачного начального запуска удаляется обычным подтверждением;
отсутствие процесса само по себе не считается доказательством пустоты.

## Проверено

Через локальную owner MTProto-сессию на тестовом боте: native `/model`,
стрелки и Enter в выборе модели/effort, Esc, возврат в карточку с моделью;
создание через браузер папок, read-only запрос с инструментом `pwd`, доставка
финала, архивация через подтверждение и возврат к предыдущей сессии.
После исправления inherited stdin повторно проверено удаление пустой сессии:
предыдущая карточка восстановлена, дополнительный CLI завершён.

Полный локальный gate: `make check build`. Отдельные регрессии проверяют
завершение реального subprocess при открытом родительском stdin, отмену,
очистку дочерних процессов, точную идентичность и отсутствие inference при
терминальном управлении. Персональные данные и MTProto-файлы вне репозитория.

## Остаток приёмки

- Live-проверка Claude через owner MTProto выполнена: запуск в `/root/bria`,
  read-only `pwd` и финал `BRIA_NATIVE_OK` подтверждены. Передача изображения
  дошла до карточки, но запрос завершился `provider_error`; совместимость
  конкретной модели с image-input требует отдельного исправления.
- Native transport поддерживает только Linux amd64/arm64 с tmux и pidfd.
  Darwin-сборка не означает работоспособность сессий; перенос lifecycle на
  Darwin остаётся незавершённым. Скрытого отката на headless transport нет.
- Docker и installer имеют проверяемую tmux-зависимость; полноценный
  запуск собранного контейнера с провайдером ещё не проверен.
- Асинхронное наблюдение native-меню добавлено 2026-09-06: подписанные клавиши
  показываются только при реальном интерактивном списке; завершение выбора
  возвращает карточку. Наблюдение привязано к точному поколению процесса,
  очередь обновлений использует общий Telegram scheduler, уход в меню отменяет
  ожидающее обновление. Набор произвольных команд не прошёл исчерпывающую
  внешнюю приёмку.
- `/new`, `/clear`, `/resume`, `/fork` внутри CLI пока явно отклоняются:
  для смены сессии используются «Новая» и «Архив», чтобы не смешать историю.
- Набор queued/steer-turns проверен компонентно; внешняя проверка всех
  сочетаний прерываний и нескольких финалов ещё нужна.
